# Notebooks

Esta pasta guarda notebooks exploratórios e históricos usados durante a construção da análise.

- `lucas.ipynb`: prototipagem/experimentos iniciais.
- `verificacao_refutabilidade.ipynb`: verificação manual do DAG e refutabilidade antes da consolidação em scripts.

Para reproduzir os resultados finais, use os scripts em `causal/` e o orquestrador `scripts/run_all_experiments.sh`.
